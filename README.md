# 動画くらべ

Windows 11 用の、2本の動画を並べて比較するデスクトップアプリです。
Python 3.12（64 bit）をインストールし、このフォルダーの `start.bat` をダブルクリックしてください。
初回はインターネット接続が必要です。依存パッケージを専用の `.venv` にインストールします。

## 使い方

1. 左右それぞれの「開く」から iPhone の MOV ファイルを選びます。
2. 各動画の下のボタンで個別に再生・停止・1コマ送り・1コマ戻しができます。
3. 上部の「両方」ボタンで、現在の各再生位置から同時に操作できます。
4. スライダーでそれぞれの位置を調整できます。例えば異なる時刻に撮影した動作の開始位置を合わせてから「両方 再生」を押します。
5. 速度は 0.25 / 0.5 / 1 / 2 倍から選択できます。

Space は両方の再生/停止、左右矢印キーは両方のコマ戻し/送りです。
どちらかが終端に達するとその動画だけ停止します。再度見るには位置を戻してください。

## 動画形式と制限

- FFmpeg を内包する PyAV で MOV / MP4、H.264 / HEVC を読み込みます。別途 VLC やコーデックの導入は不要です。
- コマ操作は実際のデコード済みフレーム単位です。フレームレートが異なる2本の「両方 1コマ」では、それぞれ1フレーム進むため経過時間は異なります。
- 同時再生は共通の時計を使いますが、厳密な業務用のフレーム同期は保証しません。高解像度・高フレームレート動画は PC の性能によって再生が遅れる場合があります。
- 縦動画の回転情報に対応しています。HDR / Dolby Vision の専用トーンマッピングは行わないため、色や明るさが iPhone と異なる場合があります。
- **音声は再生しません。** 映像比較用です。元のファイルは変更しません。
- Windows 実機と実際の iPhone 動画での確認は別途必要です。クラウドでは生成した MOV と GUI の自動検証を行っています。

## 開発

```sh
python -m venv .venv
# Windows:
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

テストには追加で `pytest` と、テスト素材生成用の `ffmpeg` コマンドが必要です。
`python -m pytest -q` を実行します。画面のない Linux では `QT_QPA_PLATFORM=offscreen` を指定します。
